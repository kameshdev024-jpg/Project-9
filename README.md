# Equity Research News Tool

An AI-powered tool built with Streamlit, LangChain, OpenAI, and NewsAPI to fetch and summarize latest financial and equity research news.

## Features
- Fetches real-time news articles based on user query using NewsAPI.
- Summarizes articles using OpenAI and LangChain for equity research analysis.
- User-friendly web interface built with Streamlit.
